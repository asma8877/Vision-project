# Camouflaged Object Detection in Complex Visual Environments Using Efficient Multi-scale Convolutional Attention Decoding (EMCAD)



Done by  Inas, Fatima, Asma

## Description: 

This project focuses on camouflaged object detection (COD) using deep learning techniques. It compares a baseline segmentation model (UNet) with a more advanced architecture (EMCAD with PVTv2-B2 encoder) on the COD10K dataset.

The goal is to accurately detect objects that blend into their surroundings, which is a challenging computer vision problem with applications in surveillance, wildlife monitoring, and autonomous systems.

## Instructions

1. Install the required libraries using pip install -r requirements.txt.
2. Download and place the COD10K dataset in the project folder.
3. Update the dataset path inside the script.
4. Run the project using python vision_project_full.py.
5. Allow the model to train and validate automatically.
6. View the saved results and predictions in the output folder.
